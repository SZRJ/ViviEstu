ViviEstu frontend (Angular)

Instrucciones rápidas para levantar el proyecto Angular creado aquí (esqueleto):

1) Instala dependencias (en la carpeta `viviestu_frontend`):

```powershell
cd "c:\Users\LUIS G\OneDrive\Escritorio\ing soft\ViviEstu\viviestu_frontend"
npm install
```

2) Levantar en modo desarrollo:

```powershell
npm run start
```

3) La app cargará en http://localhost:4200 y el componente Favoritos consumirá la API en `/api/favoritos` (por defecto el backend corre en http://localhost:8080).

Notas:
- Este es un esqueleto mínimo generado automáticamente. Ejecuta `npm install` para obtener las dependencias de Angular.
- Si ya tienes un proyecto Angular real en otra ubicación, puedo ajustar sólo los archivos del componente y servicio para integrarlos en ese proyecto.
